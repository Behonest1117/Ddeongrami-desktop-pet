## 🐰 关于 Ddeongrami

<div align="center">

<img src="Ddeongrami interface.png" width="500" alt="Ddeongrami interface">

</div>

**Ddeongrami（떵그라미，读作“咚格拉米”）** 是一只住在桌面上的粉色像素兔子。

名字来自朴星化在 ANITEEZ IN THE CALLING 档案中写下的昵称。

它平时很温柔、安静，却偶尔会做些奇怪事情；会抱紧自己的饭碗，把短尾巴藏起来，也很怕耳朵被揪住。

到了舞台上，它会突然变得凶狠；戴上墨镜后，更会彻底放飞自我。

希望梯尼在工作、学习的时候，这只小小的 Ddeongrami 会一直陪着你 ♡
